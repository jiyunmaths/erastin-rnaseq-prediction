# Project presentation

[Download the PowerPoint presentation](erastin_methods_results.pptx)

**Predicting erastin sensitivity from bulk RNA-seq** — 23 slides
(18 main slides and 5 appendix slides), exported on 2026-11-03.
The file includes editable charts and tables, plus speaker notes with sources.

The presentation covers the DepMap RNA-seq and CTRP/PRISM response cohorts,
the curated 64-gene ferroptosis panel, shared nested lineage-stratified
validation, model and panel comparisons, gene importance and direction,
and the exploratory mutation/copy-number benchmark.

The working reference remains the individual RNA-only 64-gene ridge,
Elastic Net and neural network models. The comparisons do not establish
a universal best model or causal gene effects. Repeated holdouts overlap,
and reported conditional intervals do not replace independent validation.

Results and source links are pinned to analysis commit
[`288ffff`](https://github.com/jiyunmaths/erastin-rnaseq-prediction/tree/288ffff7c9313fceaedb25cba5c9fc35c54a8ec9).
This export adds no new model fits or benchmark results.
